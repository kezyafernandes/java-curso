# ☕ Meus Projetos em Java

Aprendendo Java do zero, com um projeto real de **Agenda de Contatos**.

## 📁 Estrutura

- `01-basico/` — exercícios das aulas (variáveis, if/else, loops, arrays, classes...)
- `Agenda.java` + `Contato.java` — **Agenda de Contatos** (projeto principal)

## 🚀 O projeto: Agenda de Contatos

Um CRUD completo no terminal:

- ✅ Adicionar contato
- ✅ Listar contatos
- ✅ Buscar contato
- ✅ Remover contato

### Como rodar

```
cd 01-basico
javac Agenda.java
java Agenda
```
